updater
=======

Aquaria updater and installation tool for macOS.

## Supported Architectures

- **arm64** (Apple Silicon / M-series) - Tested on M4
- **x86_64** (Intel 64-bit) - Maintained for compatibility
- **i386** (Intel 32-bit) - Maintained for compatibility
- **i686** (Intel 32-bit) - Maintained for compatibility

Note: PowerPC (PPC) architecture is not supported.
